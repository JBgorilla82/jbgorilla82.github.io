# B&S Roofing — single-page website concept

A responsive concept site prepared by JB Digital Designs for private outreach. It is a design proposal, not a live site.

## Preview
Open `index.html` in a browser. The stylesheet, logo and HTML should remain in the same folder.

## Important before any public launch
- Confirm B&S Roofing's exact service list, service area, business name and any claims with the business.
- Confirm and replace the Checkatrade search URL with the direct B&S Roofing profile URL.
- Add the correct phone number, email address and a real enquiry destination/form backend.
- The enquiry form is demonstration-only and does not transmit or store submissions.
- The roofing photography is externally hosted illustrative stock imagery; replace with B&S Roofing's own approved project photos where possible.
- Confirm permission to use the supplied logo before publishing the site publicly.
- Rating shown (9.92/10, 54 reviews) was taken from a Checkatrade search listing during concept research and should be rechecked before launch.

## Design direction
Deep navy and bright yellow echo the supplied B&S logo. The layout prioritises service clarity, mobile enquiry access, review visibility and local relevance. It is inspired by common effective roofing-site patterns, not copied from RoofSurv Dorset.
